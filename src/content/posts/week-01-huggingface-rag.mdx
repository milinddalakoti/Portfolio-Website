A reproducible, modular **Mini-RAG Reader** in
[`milinddalakoti/ireland-visa-journey/projects/01-mini-rag-reader/`](https://github.com/milinddalakoti/ireland-visa-journey/tree/main/projects/01-mini-rag-reader):

1. **PDF ingestion** (`pdfplumber`) → per page records.
2. **Sliding window chunking** (500 char windows, 50 char overlap) → `Chunk` objects with provenance.
3. **Embedding** (`sentence-transformers/all-MiniLM-L6-v2`, 384 dim, L2 normalised).
4. **FAISS `IndexFlatIP`** for cosine similarity retrieval.
5. **Open weights LLM** (`Llama-3.2-3B-Instruct` via Hugging Face `transformers`) with a strict citation forcing system prompt.
6. **FastAPI** wrapper with `/health`, `/load`, `/ask`.

**14/15 tests green** (1 skipped is the model load test, opt in).

## What I learned

- **RAG is not "just call an LLM"** — chunking strategy materially changes retrieval recall.
- **System prompt engineering matters more than I expected** — the citation forcing prompt is the difference between a usable answer and an unverifiable one.
- **Astro 7 + Tailwind 4 changes the integration story.** `@astrojs/tailwind` only supports Astro 3–5; for Astro 7 you must use `@tailwindcss/vite` directly.
