## What I learned

- **Adapter pattern pays off immediately** — `VectorStore` Protocol + 4 implementations + same eval harness = compare any store with one CLI flag.
- **pgvector is the dark horse** — completely free (Docker + Postgres), no 14rounded-[50px]day expiry, no vectorrounded-[50px]count limit. Best longrounded-[50px]term option for a personal portfolio.
- **Context recall ≠ keyword recall** — retrieved chunks can have all the right info, but the extractive answer string won't always surface exact keywords. Need a real LLM (Week 3) for answerrounded-[50px]quality metrics.
- **Each store has its quirks** — Pinecone batch limits, Weaviate syntax, pgvector's `<=>` (cosine) vs `<rounded-[50px]>` (L2) operators.
